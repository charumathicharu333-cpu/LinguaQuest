# LinguaQuest Store Listing Draft

## Short description
Turn screen time into fun, offline learning adventures.

## Full description
Explore a world of useful ideas, one short quest at a time. LinguaQuest turns everyday screen time into a playful journey through language, science, geography, logic, and more.

Choose an age trail, pick a language, and set off from Welcome Village. Learn a few new words, solve a puzzle, finish a friendly quiz, and see your map grow. English, Hindi, and Japanese starter trails are included. Science, geography, general knowledge, and logic packs add 80 original quiz questions.

Built offline-first: lessons, games, questions, and progress are stored on the device after installation. No account is needed to start.

Designed for healthy use. Quests are short, progress is encouraging, breaks are welcome, and there are no lost lives or streak penalties. No public chat, precise location, or targeted advertising is included in this MVP.

## Feature list
- Eleven original map locations with progressive XP unlocks
- English, Hindi, and Japanese beginner vocabulary trails
- Multiple choice, word match, sentence builder, memory cards, timed quiz, picture clue, and logic puzzle games
- 80 offline knowledge questions across four topics
- Local XP, levels, a gentle learning rhythm, and achievement badges
- Parent dashboard with learning-time estimate and topic summary
- No account required; core MVP content remains free

## Privacy note
The MVP stores the selected age range, language, activity, XP, achievements, and settings in a local SQLite database. It does not request a real name, contacts, precise location, cloud account, or public profile. There is no analytics or advertising SDK in this project.
