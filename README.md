# LinguaQuest
🌍 **LinguaQuest** — A fun, offline-first, game-based learning app that turns screen time into learning time through languages, quizzes, missions, and educational challenges. 🎮📚

**Turn Screen Time Into Learning Time. 🎮📚**

LinguaQuest is an **offline-first, game-based learning app** designed to make learning fun and engaging for kids, students, and adults.

### ✨ Features

* 🎮 Game-based learning
* 🌍 English, Hindi & Japanese
* 🧠 Science, Geography, History, GK & Logic
* 🗺️ Adventure map & missions
* 🏆 XP, levels, streaks & badges
* 🧩 Interactive quizzes and mini-games
* 📱 Offline-first learning
* 👨‍👩‍👧 Parent-friendly progress tracking

### 🛠️ Tech Stack

**Flutter • Dart • SQLite • Local JSON**

### 🚀 Run Locally

```bash
flutter pub get
flutter run
```

### 🔍 Verify & Build

```bash
flutter analyze
flutter test
flutter build appbundle
```
